# Meta Ads Policy Pages

This repository contains public policy pages for Meta Ads integrations used with Hermes.

## Systems

### Nahuel Ads Manager

Internal tool for Nahuel's personal investment-focused social media presence.

- Privacy Policy: `nahuel-ads-manager/privacy-policy.md`
- User Data Deletion: `nahuel-ads-manager/data-deletion.md`

### Scalynn Ads Manager

Internal business tool for Scalynn to analyze, report, and manage Meta Ads campaigns for Scalynn and authorized client ad accounts.

- Privacy Policy: `scalynn-ads-manager/privacy-policy.md`
- User Data Deletion: `scalynn-ads-manager/data-deletion.md`

## Notes

These documents are intended to be used as public URLs required by Meta Developer Apps, including:

- Privacy Policy URL
- User Data Deletion URL

No API tokens, credentials, or secrets should ever be stored in this repository.
